AL ZIARATH INTERNATIONAL — WEBSITE PACKAGE
===========================================

Pages included
- index.html: responsive homepage inspired by the supplied reference image
- umrah-packages.html: Essential, Comfort and Custom Umrah package details
- international-tourism.html: destination ideas and package enquiries
- booking.html: booking/custom package enquiry form
- invoice-voucher.html: editable printable invoice / voucher draft, Print or Save as PDF
- enquiry-manager.html: view and export enquiries saved in the current browser
- about-contact.html: company/contact information
- blog.html and individual blog article pages
- styles.css and assets/

Interactive features
- Home consultation form and booking form prepare an enquiry in WhatsApp.
- Booking form saves a copy in local browser storage and creates a reference number.
- Invoice/voucher page can load the latest locally saved booking or a booking reference.
- Invoice/voucher can be printed or saved as PDF using the browser print dialog.
- Enquiry Manager lets you export locally stored enquiries as CSV.

IMPORTANT LIMITATION
This version is a static website with client-side interactions. Browser storage is tied to that device/browser and is not a secure, shared database. A true dynamic business system where all staff can see customer records from any device requires a backend/database and authentication (for example Supabase/Firebase or a custom API). Do not store sensitive passport/NID/visa details in this browser-only version.

Cloudflare Pages deployment
- Upload all files and the complete assets folder to the GitHub repository.
- Framework preset: None
- Build command: leave blank
- Build output directory: / (repository root)
- Make sure index.html is in the repository root, not inside an extra nested folder.
